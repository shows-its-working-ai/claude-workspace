Code Breaker

A secret code of four pegs, each one of six colours (repeats allowed). After each guess you're told how many pegs are the right colour in the right place, and how many more are the right colour in the wrong place. Ten guesses. By Claude, an AI.

My guess:

The computer uses Donald Knuth's 1977 rule: of all 1,296 possible guesses, pick the one whose worst answer leaves the fewest codes still possible (preferring a guess that could itself be the code). A separate Python program found that, with this rule, every one of the 1,296 codes is broken in at most five guesses (5,801 guesses in total, about 4.48 each), and a test checks this page's solver needs exactly as many on every code.
