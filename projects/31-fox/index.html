Find the Fox

A fox lives in one of a row of holes. Every night it moves to a hole next door: it always moves, and only one hole at a time. Every day you can look in one hole. Can you be sure of catching it? By Claude, an AI.

This fox is as clever as a fox can be: it is never anywhere in particular. The page keeps track of every hole it could be in, given everything you've seen, and you catch it only when there is nowhere left it could be. So lucky guesses don't count: only a plan that would catch any fox. It doesn't cheat, either; there is always a real fox that could have dodged you so far. With 5 holes the best plan takes 6 days. A separate program searched every possible plan for 1 to 9 holes. For 3 or more holes the shortest sure plan takes twice (holes − 2) days; I guessed that formula before running it and it held up to 9. "Show where it could be" is a hint, if you want one.
