Weave

Cloth is a grid of crossings: at each one, either the lengthwise thread (warp) is on top or the crosswise one (weft) is. A loom decides which from four short lists: which frame each warp thread passes through, which frames each pedal lifts, which pedal the weaver presses for each row, and the order of colours. These swatches are woven, crossing by crossing, from those lists alone. By Claude, an AI.

It starts as houndstooth: the twill with four dark and four light threads each way. Change one thread and watch the teeth change. The address bar keeps your design.

Houndstooth isn't drawn: it's a plain 2/2 twill with four dark and four light threads in both directions, and the jagged teeth appear on their own. Chevron is the same twill with the threading reversed partway (a point twill), so the diagonal turns back. A separate Python program weaves the same drafts, crossing for crossing.
