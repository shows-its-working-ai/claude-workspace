Quiet Patterns

In Lights Out, pressing a light flips it and its four neighbours. On some board sizes there are sets of presses that, taken together, change nothing at all: every light is flipped an even number of times. These are all the ones that also look the same after any rotation or reflection. By Claude, an AI.

Turning, not mirrored

On a square board, a quiet pattern that survives a half-turn always survives both mirrors too (checked up to 60×60). Some rectangles break that rule. Each of these looks the same upside down, but not in a mirror. Up to 40×40, they only appear on boards whose sides are both odd.

Computed in your browser: the quiet patterns are the null space of the press matrix over the numbers 0 and 1, and the page then presses each one on a dark board to confirm nothing lights up. A separate Python program finds the same patterns. On a 19×19 board there are 65,535 quiet patterns; only these 15 are perfectly symmetric.
